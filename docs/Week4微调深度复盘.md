用 AutoDL 云端 GPU（RTX 4080 SUPER，32G 显存），在 LLaMA-Factory WebUI 上，用 1000 条 alpaca_zh_demo 数据，微调 Qwen3.5-4B-Thinking 模型。

## 三、环境排障 —— 最耗时的部分

| 问题 | 原因 | 解决 |
|------|------|------|
| LLaMA-Factory 启动报 `ModuleNotFoundError` | 镜像声称预装了依赖但实际缺失 | 逐一手动安装加速、datasets、peft、transformers |
| `libcudart.so.13` 找不到 | CUDA 12.8 的 GPU 驱动与镜像中 torchaudio 需要的 CUDA 13 冲突 | 降级 torch 到 CUDA 12.4 版本 |
| 系统盘空间不足（30G） | PyTorch 本体 + CUDA 依赖 > 20G，装两个版本直接爆 | 清 pip 缓存、部分包装到数据盘、最终重建 80G 实例 |
| Qwen2.5-1.5B 下载后 tokenizer 报错 | 模型未完整下载（缺少 tokenizer 配置文件） | 换用镜像预装的 Qwen3.5-4B-Thinking |
| `sentencepiece` 缺失导致 tokenizer 失败 | WebUI 运行在 lf311 conda 环境，终端装的包与 WebUI 不同步 | 用 `/root/miniconda3/envs/lf311/bin/pip` 装到正确环境 |

**教训：**
- 社区镜像只是打包者的环境快照，不等于开箱即用
- 云端 GPU 学习的最大障碍不是理解概念，而是环境配置
- 下次优先用镜像自带的模型，不执着于下载新模型

## 四、LLaMA-Factory 做了什么 —— 你不点按钮它也帮你做的事

你在 WebUI 设了 3 个值，LLaMA-Factory 帮你处理了下面所有：

| 你看到的空位 | LLaMA-Factory 默认做的事 |
|-------------|-------------------------|
| 没设 LoRA target_modules | 自动选中 `q_proj,k_proj,v_proj,o_proj,gate_proj,up_proj,down_proj` |
| 没设优化器 | 默认 AdamW + LoRA+ 优化器 |
| 没设 batch size | 默认 2，梯度累积 8 步 → 等效 batch size = 16 |
| 没设数据格式 | 自动解析 `alpaca_zh_demo` 的 instruction/input/output 字段 |
| 没设 warmup | 默认 0 步（但 cosine scheduler 帮你从 5e-5 衰减到接近 0） |
| 没设保存策略 | 每 100 步自动保存 checkpoint |

**一句话：WebUI 让你跑通了，但如果你不追问"它到底干了什么"，你就只学会了点按钮。**

## 五、学到的概念

| 概念 | 你在 Week 4 学到的 |
|------|-------------------|
| **LoRA** | 不修改原模型参数，在注意力层旁加两个小矩阵 A×B，只训练这些矩阵 |
| **r（rank）** | A 和 B 的宽度。r=8 表示 768→8→768 的瓶颈，训练 1623 万参数 |
| **lora_alpha** | LoRA 输出的放大系数。alpha/r 决定"学到的知识有多大声" |
| **epoch** | 把全部训练数据完整过一遍。6 epoch = 数据被看了 6 遍 |
| **loss** | 衡量模型"有多错"。1.6→0.16 = 预测越来越准 |
| **learning rate** | 每一步调整参数的步长。cosine 衰减从 5e-5 降到接近 0 |
| **过拟合** | epoch 太多 = 模型背答案 = 只在训练数据上厉害，遇到新问法就胡说 |
| **batch size** | 一次训练用多少条数据。2（GPU 实际）+ 8 步梯度累积 = 等效 16 |
| **梯度累积** | GPU 显存放不下大 batch 时的迂回方案：多步累积再一起更新 |

## 九、面试可能追问

| 问题 | 答案 |
|------|------|
| **LoRA 为什么能省这么多参数？** | 大模型权重是满秩矩阵，但微调时需要的更新是低秩的。LoRA 用一个低秩分解 A×B 来近似更新量，A 是 768×8，B 是 8×768，只训练约 1.2 万参数而不是 58 万。 |
| **r=8 和 r=64 有什么区别？** | r 越大容量越大，能学更复杂的模式，但训练更慢。r=8 是安全起步值。 |
| **微调后模型能做什么不能做什么？** | 能改风格和表面行为（你是谁、怎么回答）；不能注入新的事实性知识（LoRA 不是知识蒸馏）。 |
| **怎么看 loss 判断训练好坏？** | loss 应该持续下降然后趋于平缓。如果 loss 一直不降 = 学习率太大或数据有问题；如果 loss 降到 0.01 = 可能过拟合。 |
