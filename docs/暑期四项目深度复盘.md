## 二、每个项目的核心逻辑

### Week 1 — 基础：学会"调 API"

```
用户输入 → while True 循环 → client.chat.completions.create(
    model="deepseek-v4-pro",
    messages=[...],
    stream=True           ← 打字机效果
) → 逐字打印回复
```

**项目结构：** `main.py`（交互循环）→ `chat.py`（API 封装）→ `config.py`（Pydantic 校验）→ `utils.py`（装饰器+上下文管理器）

**学到的工程技能全在这个项目里：** `@retry` 自动重试、`TokenCounter` 上下文管理器、`LLMConfig` Pydantic 类型校验、`send_streaming` 流式输出、`setup_logging` 结构化日志。

---

### Week 2 — 检索增强：学会"喂知识"

```
上传 PDF → pypdf 提取文字 → split("\n") 切段
  → sentence-transformers 向量化（384 维）
  → ChromaDB 存储
  → 用户提问 → 向量化搜索 → 拼接 Prompt → DeepSeek 回答
```

**关键决策：** DeepSeek 不提供 Embedding API → 用本地 `all-MiniLM-L6-v2` 模型（免费、离线、快）。HuggingFace 被墙 → `hf-mirror.com` 镜像。

**复盘发现的 Bug：** `ask()` 函数内部重复调用 `search()`，每次提问向量检索跑了两次。修复：搜索结果作为参数传入。

---

### Week 3 — Agent：学会"做事"

```
用户: "特斯拉股价？"
  → LLM 决定调用 search_web("特斯拉股价")
  → Tavily API 真实搜索 → 返回结果
  → LLM 组织语言 → "313 美元，来源 TradingView"
```

**自建 ReAct 循环：**

```python
for step in range(max_steps):
    response = LLM(messages, tools)
    if 没有 tool_calls:
        return 回答
    执行工具 → 结果加入 messages → 继续循环
```

**最终能力：** 5 个工具（搜索、计算、天气、记忆保存、记忆搜索）、短期记忆（消息清理）、长期记忆（ChromaDB 跨对话）、Planning（System Prompt 工程）。

**关键认知：** 30 行核心代码就能写一个 ReAct Agent。不需要 LangChain。

---

### Week 4 — 微调：学会"改模型"

```
1000 条 alpaca_zh_demo 数据
  → Qwen3.5-4B-Thinking（45 亿参数）
  → LoRA（只训练 0.36% = 1623 万参数）
  → 66 分钟训练，loss 1.63 → 0.16
  → 模型身份从"Qwen官方"变成"通用助手"
```

**关键参数：** r=8（LoRA 容量）、alpha=16（输出放大）、epoch=6（训练轮数）、cosine 学习率衰减。

**最耗时环节：** 不是训练本身，而是环境配置——CUDA 版本冲突、系统盘爆满、conda 环境隔离。

## 五、踩过的最有价值的坑

| 坑 | 项目 | 学到的 |
|----|:--:|------|
| `parameters` 拼成 `paramaters` | Week 3 | API 字段名一个字母都不能错 |
| `return` 缩进在 for 里面 | Week 3 | 循环里 return = 只执行一次 |
| HuggingFace 被墙 | Week 2 | `hf-mirror.com` 镜像 + ModelScope |
| DeepSeek 没有 Embedding API | Week 2 | 查 GitHub Issues 验证，不瞎猜 |
| LLM 假装调用了工具 | Week 3 | System Prompt 硬约束 |
| DuckDuckGo 国内不稳 → Tavily 字段名不匹配 | Week 3 | 换 API 要逐字段检查 |
| LLaMA-Factory 环境 2 小时排障 | Week 4 | CUDA 版本、conda 环境、系统盘大小 |
| `msg` 存为对象不能下标 | Week 3 | `msg.model_dump()` 转 dict |
| Streamlit `st.button` + `file_uploader` 冲突 | Week 2 | Streamlit 每次交互重跑整个脚本 |

## 六、如果重新做一遍

| 当时的问题 | 现在的解法 |
|-----------|-----------|
| 不知道文件怎么分工 | 先画依赖图：main→chat→config，底层不依赖上层 |
| PDF 扫描版提不出文字 | 先用 txt 测试核心链路，再处理 PDF |
| 跟 LLaMA-Factory 环境死磕 | 镜像自带什么模型就用什么，跑通最重要 |
| 执着于写完整功能才验证 | 每个项目先写 20 行核心链路跑通，再包装 |
